# 🔢 Counter

Um contador interativo desenvolvido com **React** e **Vite**, com foco no aprendizado de desenvolvimento front-end, gerenciamento de estados e componentização.

## ✨ Funcionalidades implementadas

- [x] Incrementar o contador.
- [x] Decrementar o contador.
- [x] Impedir que o contador fique negativo.
- [x] Resetar o contador.
- [x] Alterar o valor do incremento.
- [x] Validar a entrada do novo incremento.
- [x] Criar componentes reutilizáveis.
- [x] Interface responsiva e estilizada com Tailwind CSS.

## 🚧 Funcionalidades futuras

- [ ] Definir limite mínimo e máximo para o contador.
- [ ] Permitir alterar os limites pela interface.
- [ ] Criar histórico de operações.
- [ ] Implementar a função de desfazer a última operação.
- [ ] Salvar os dados no navegador utilizando LocalStorage.
- [ ] Implementar modo de contagem automática.
- [ ] Permitir configurar a velocidade da contagem automática.

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- Vite
- Tailwind CSS

## 💻 Como executar o projeto

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd contador
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

## 📚 Objetivo do projeto

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento front-end.

O objetivo é praticar conceitos fundamentais do React, como `useState`, props, callbacks, componentes reutilizáveis, manipulação de eventos e validação de dados, evoluindo gradualmente a aplicação com novas funcionalidades.
